# Architecture

The suite is organized as a set of small modules.

## Pipeline

1. Input paper abstract or PDF text
2. Parse metadata and abstract components
3. Extract claims and contributions
4. Retrieve relevant evidence chunks
5. Generate citation-grounded answer
6. Evaluate answer quality
7. Store benchmark results
8. Visualize results in dashboard

## Main components

- Abstract analysis
- Research QA
- Claim extraction
- Evaluation metrics
- Benchmark runner
- Dashboard
